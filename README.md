# 2027 大阪・京都 7 天旅行計畫

2027/2/11–2/17 的大阪、京都與宇治自由行網站，整理每日點到點路線、交通票券、在地高評美食、日本製茶筅採買與出發前待辦。

## 網站功能

- 7 天每日時間軸與交通方式
- 地圖、店家官網與資料來源捷徑
- 燒肉、拉麵、豬排與甜點清單
- 京都抹茶與奈良高山製茶筅購買方案
- 票券成本比較與使用提醒
- 可勾選並保存在自己瀏覽器的行前待辦
- 手機、平板與桌面版響應式版面

## 本機使用

需要 Node.js 22.13 以上版本。

```bash
npm ci
npm run dev
```

建立 GitHub Pages 靜態檔案：

```bash
npm run build:pages
```

輸出位於 `docs/`，GitHub Pages 設定為從 `main` 分支的 `/docs` 發布。

## 資料時效

餐廳分數、價格、營業日與票價查核日為 2026/08/13。2027 年 1 月需再確認臨時店休、價格、班次與茶筅庫存；航班時間以電子機票為準。
